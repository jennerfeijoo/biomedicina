# Política de seguridad

## Alcance

Se aceptan informes sobre generación y publicación de contenido, dependencias, workflows, autenticación futura, privacidad, aislamiento de datos y exposición accidental de material protegido.

## Cómo informar

Utilice el sistema privado de reporte de vulnerabilidades de GitHub cuando esté disponible. Si no aparece esa opción, abra un issue que solicite un canal privado sin incluir explotación, secretos, datos personales ni detalles que aumenten el riesgo.

Incluya versión o commit, componente afectado, impacto, pasos mínimos de reproducción y mitigación propuesta. No use datos clínicos reales ni cuentas de otras personas durante las pruebas.

## Respuesta

El mantenedor confirmará recepción, evaluará severidad, limitará la exposición y documentará la corrección. Un incidente que afecte la integridad científica suspende también el registro de validez del revisor relacionado hasta completar la investigación.
