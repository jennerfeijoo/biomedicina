# Política de privacidad y datos de aprendizaje

## Estado actual

La versión pública actual no ofrece cuentas ni almacena progreso personal. Esta política define las condiciones que deben cumplirse antes de habilitar esas funciones.

## Minimización

La plataforma solo recogerá los datos necesarios para autenticación, progreso, intentos, feedback y logros. No solicitará datos clínicos, diagnósticos, historia médica, biomuestras ni información sensible para personalizar el estudio.

## Derechos del estudiante

La persona debe poder:

- consultar qué datos se conservan;
- exportar progreso, intentos y logros;
- corregir datos de perfil;
- eliminar la cuenta y los datos asociados;
- usar un modo invitado cuando la sincronización no sea necesaria;
- conocer qué versión del contenido produjo cada resultado.

## Seguridad

Cada registro privado debe asociarse a `user_id` y protegerse con controles de acceso por fila. Las pruebas deben demostrar que una cuenta no puede leer ni modificar datos de otra. Las credenciales y claves administrativas nunca se incluirán en el cliente ni en el repositorio.

## Retención y borrado

La retención se definirá antes del lanzamiento del MVP. El borrado solicitado debe cubrir perfil, progreso, intentos y logros, salvo registros mínimos que deban conservarse por una obligación documentada. Los respaldos deben tener plazos de expiración.

## Investigación educativa

El uso de datos de aprendizaje para investigación requiere información clara, base ética y legal aplicable, minimización, separación entre operación e investigación y publicación agregada. El consentimiento para investigar no debe condicionarse al acceso al contenido educativo.
