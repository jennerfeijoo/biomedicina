La Unidad 3 cuenta con borrador autoral y auditoría interna. Este paquete prepara dos revisiones reales que siguen pendientes:

- revisión humana de `U3-A5`;

## Revisión humana de U3-A5

La tarea compara ECG, EEG y EMG por fuente, geometría, escala, banda, interfaz y límite de inferencia. La rúbrica usa seis dimensiones de 0 a 2 puntos. La decisión no puede automatizarse y requiere registro de identidad o seudónimo, cualificación, fecha, puntuaciones, comentarios y declaración de conflicto de interés.

## Revisión profesional

La revisión disciplinar debe examinar terminología, modelo de interfaz, conducción de volumen, taxonomía de nodos, artefactos, límites no diagnósticos, seguridad y alineación evaluativa. El revisor debe registrar hallazgos por severidad y una decisión explícita.

## Límites

- No se recogen datos de participantes en este paquete.
- No se conectan electrodos a personas.
- No se demuestra seguridad ni conformidad normativa.
- No se interpreta ECG, EEG o EMG clínicamente.
- No se autoriza publicación.
