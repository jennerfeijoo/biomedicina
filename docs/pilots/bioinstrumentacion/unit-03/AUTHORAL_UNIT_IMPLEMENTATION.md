# Bioinstrumentación · Unidad 3 · Implementación autoral

## Estado

La Unidad 3, **Biopotenciales, electrodos e interfaz electrodo-tejido**, se incorpora como borrador autoral en estado `review`.

## Integración

La unidad conecta cinco niveles que deben mantenerse separados:

1. potencial transmembrana y corrientes iónicas;
2. fuentes bioeléctricas distribuidas;
3. conducción de volumen;
4. interfaz electrodo-electrolito-tejido;
5. medición diferencial.

Incluye seis secciones teóricas, tres ejemplos resueltos, las prácticas U3-P1 a U3-P3, las evaluaciones U3-A1 a U3-A5 y doce rutas de recuperación conceptual.

## Hallazgos menores incorporados

La redacción declara explícitamente que Rs, Rct, Cdl y el potencial de media celda dependen de material, área, preparación, frecuencia, presión, hidratación, temperatura y tiempo. No se presentan como constantes universales.

La comparación de ECG, EEG y EMG permanece técnica y no diagnóstica. Se mantienen visibles las inferencias prohibidas.

## Límites

- no se autoriza adquisición con personas;
- no se autoriza conexión física de electrodos;
- no se realiza diagnóstico;
- no se afirma seguridad o conformidad mediante simulación;
- U3-A5 continúa pendiente de revisión humana;
- la revisión profesional continúa pendiente;
- la publicación continúa bloqueada;
- el curso permanece `pending`.

## Evidencia previa

La unidad referencia contratos de preparación, resolución de bloqueos, prácticas, evaluación y auditoría interna. La existencia de este borrador no cambia el estado editorial general del curso.
