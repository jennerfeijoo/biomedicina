# Implementación de evaluación · Bioinstrumentación Unidad 3

Se implementan cinco evaluaciones alineadas con `U3-LO1` a `U3-LO5`.

- `U3-A1`: reconstrucción de la cadena desde potencial transmembrana hasta diferencia superficial.
- `U3-A2`: interpretación limitada del modelo `Rs + (Rct || Cdl)`.
- `U3-A3`: clasificación funcional de referencia, retorno, tierra de protección y blindaje.
- `U3-A4`: diagnóstico de artefactos mediante patrón, mecanismo y prueba discriminante.
- `U3-A5`: comparación ECG–EEG–EMG mediante rúbrica humana.

Las rutas de feedback corresponden uno a uno con los doce errores conceptuales de la preparación. El feedback es progresivo, no revela respuestas completas y exige resolver un caso distinto antes de continuar.

## Límites

- No existe puntuación semántica automática para tareas abiertas.
- `U3-A5` requiere confirmación humana.
- No se permite diagnóstico clínico.
- No se afirma seguridad ni conformidad.
- No se crea ni publica `unit-03.json`.
- Bioinstrumentación permanece en `pending`.
