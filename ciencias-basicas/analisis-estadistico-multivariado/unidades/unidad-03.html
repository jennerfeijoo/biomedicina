Desarrollo 1

PCA como rotación y aproximación

El análisis de componentes principales busca direcciones ortogonales que maximizan varianza sucesiva. Puede formularse como autodescomposición de la covarianza o como SVD de la matriz centrada. Los scores son coordenadas de observaciones en el nuevo sistema; las cargas relacionan variables con componentes. Cambiar el signo de una componente no altera la solución, por lo que el signo aislado no tiene significado.

PCA es descriptivo y depende del escalado. Sobre covarianza privilegia variables con mayor varianza absoluta; sobre correlación asigna peso relativo. Ninguna opción es universal. Si la variabilidad técnica es grande, las primeras componentes pueden representar lote o intensidad total, no biología. La interpretación requiere relacionar scores, cargas y metadatos, y comprobar si la estructura persiste al cambiar preprocesamiento.

La aproximación de rango k minimiza error cuadrático bajo la geometría elegida. Esto no significa que las primeras k componentes sean las más útiles para una pregunta clínica. Varianza alta puede ser irrelevante para el desenlace y señales pequeñas pueden ser importantes. PCA no supervisa la decisión y no debe presentarse como selección automática de biomarcadores.

Una práctica compara PCA mediante autodescomposición y SVD. Las soluciones coinciden salvo convenciones, pero SVD evita formar explícitamente X transpuesta por X y suele ser más estable. Esta comparación conecta geometría e implementación y muestra por qué algoritmos pueden producir pequeñas diferencias numéricas sin representar desacuerdo científico.

Puntos de integración

  • PCA rota la representación.
  • Scores y cargas son distintos.
  • El escalado define la solución.
  • Varianza no equivale a relevancia clínica.

Desarrollo 2

Varianza explicada y selección

La proporción de varianza explicada divide cada autovalor por la suma total. El scree plot permite visualizar decaimiento, pero elegir por un codo es subjetivo. Reglas como Kaiser dependen de estandarización y pueden sobreseleccionar. Análisis paralelo compara autovalores observados con datos nulos y ofrece una referencia, aunque también depende del modelo nulo.

El número de componentes debe vincularse al uso: visualización, reconstrucción, compresión, preprocesamiento o inferencia. Para predicción, k se elige dentro de validación. Para interpretación, se evalúan estabilidad y coherencia de cargas. Retener componentes hasta un porcentaje arbitrario no garantiza que la representación sea estable ni útil.

En alta dimensión, autovalores muestrales están sesgados y componentes cercanas pueden intercambiarse entre remuestras. Una dirección individual puede ser inestable aunque el subespacio conjunto sea estable. Por eso se comparan ángulos de subespacio, correlaciones de scores y variabilidad de cargas, no solo el scree plot.

Para seleccionar componentes en exploración se combinan scree plot, análisis paralelo y estabilidad. Ningún criterio se aplica mecánicamente. Se registra cómo cambia k bajo escalados distintos y si las conclusiones dependen de conservar una componente adicional. Esta sensibilidad forma parte del resultado.

Puntos de integración

  • Varianza explicada necesita contexto.
  • El codo no es una prueba.
  • k depende del objetivo.
  • Subespacios pueden ser más estables.

Desarrollo 3

Biplots, cargas e interpretación

Un biplot representa observaciones y variables en un plano común, pero existen escalados distintos. La longitud y ángulo de vectores dependen de la convención. Interpretar ángulos como correlaciones solo es aproximado bajo escalado apropiado y buena representación. Las variables mal representadas en las primeras componentes no deben interpretarse por su proyección.

Las cargas grandes señalan contribución a una componente, pero no causalidad ni importancia independiente. Variables correlacionadas suelen compartir patrones. Etiquetar una componente como inflamación o gravedad requiere evidencia externa y no solo observar algunos nombres de variables. Rotaciones pertenecen a objetivos diferentes y deben declararse.

Las visualizaciones incluyen porcentaje explicado, escalado, densidad o incertidumbre y metadatos técnicos. La separación aparente puede depender de pocos atípicos. Un gráfico responsable muestra observaciones, identifica solapamiento y evita ejes recortados que exageren diferencias.

Regiones de confianza para scores pueden estimarse por remuestreo, aunque la comparación exige alinear componentes. Mostrar solo centroides oculta dispersión. En biomedicina, la visualización debe incluir observaciones o densidades y evitar el uso de elipses como si fueran límites diagnósticos.

Puntos de integración

  • Los biplots dependen de convenciones explícitas de escalado y representación.
  • Las cargas no son causalidad.
  • Nombrar componentes requiere evidencia.
  • La separación visual debe auditarse.

Desarrollo 4

Estabilidad, validación y extensiones

Bootstrap y particiones repetidas permiten evaluar estabilidad de scores, cargas y varianza explicada. Como las componentes pueden cambiar de signo o permutarse, deben alinearse antes de comparar. La estabilidad de selección puede medirse por frecuencia o similitud de subespacios. Un PCA reproducible declara semilla, algoritmo, escalado y tratamiento de faltantes.

PCA robusto busca reducir influencia de atípicos, mientras sparse PCA impone cargas con ceros. Estas variantes cambian el estimando y requieren parámetros. No deben compararse solo por gráficos más limpios. Se evalúan reconstrucción, estabilidad, sensibilidad y coherencia con la pregunta.

En biomedicina, PCA se usa para calidad, visualización, reducción y detección de batch. Corregir componentes asociadas a lote puede eliminar biología si lote y grupo están confundidos. El análisis verifica el diseño y compara antes y después, preservando efectos de interés y evitando afirmar que una proyección corregida es verdadera.

Cuando PCA se usa antes de clasificación, la base debe estimarse dentro de cada fold. Calcularla con todo el conjunto filtra información aunque no use etiquetas. Los métodos no supervisados también pueden causar leakage cuando forman parte de un pipeline evaluado.

Puntos de integración

  • Las componentes requieren alineación.
  • PCA robusto cambia el objetivo.
  • Corregir batch puede eliminar biología.
  • PCA también puede causar leakage.

Ejemplos y casos resueltos

PCA de expresión génica

Situación. Las primeras componentes separan centros.

Razonamiento paso a paso

  1. Revisar lotes.
  2. Comparar escalados.
  3. Examinar cargas.
  4. Remuestrear.

Interpretación. La estructura dominante puede ser técnica.

Limitaciones

  • Grupo y centro pueden estar confundidos.
  • Las cargas pueden ser inestables.

PCA antes de clasificación

Situación. Se calcula PCA con todo el conjunto antes de cross-validation.

Razonamiento paso a paso

  1. Identificar leakage.
  2. Mover PCA dentro del fold.
  3. Reevaluar desempeño.
  4. Comparar estabilidad.

Interpretación. El preprocesamiento no supervisado también forma parte del modelo.

Limitaciones

  • El tamaño puede ser pequeño.
  • Puede existir shift externo.

Glosario disciplinar

  • PCA

    Rotación ortogonal que ordena varianza.

  • SVD

    Descomposición matricial en valores singulares.

  • Score

    Coordenada de una observación.

  • Carga

    Relación de una variable con una componente.

  • Autovalor

    Varianza asociada a una dirección.

  • Biplot

    Representación conjunta de observaciones y variables.

  • Scree plot

    Gráfico de autovalores ordenados.

  • Análisis paralelo

    Comparación con autovalores nulos.

  • Subespacio

    Conjunto de direcciones retenidas.

  • Sparse PCA

    PCA con cargas regularizadas y ceros.

  • Reconstrucción

    Aproximación de datos desde componentes.

  • Alineación

    Ajuste de signos y orden entre soluciones.
