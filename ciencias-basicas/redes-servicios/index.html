Redes y Servicios

Curso completo de Redes y Servicios orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Nivel
Pregrado universitario intermedio y avanzado
Estado editorial
Unidades desarrolladas · revisión experta pendiente

Guía educativa abierta: organiza un recorrido universitario, pero no sustituye el programa oficial de una institución ni otorga certificación.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Base para sistemas distribuidos de salud y plataformas clínicas.

Prerrequisitos recomendados

  • Fundamentos de programación: variables, control de flujo, funciones y archivos.
  • Álgebra y razonamiento lógico de nivel universitario inicial.
  • Uso básico de terminal, control de versiones y documentación técnica.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Redes y Servicios.
  • Aplicar el flujo definir servicio y activos → modelar capas y flujo → instrumentar → probar condiciones nominales y de fallo → documentar controles a casos nuevos.
  • Seleccionar y documentar capturas controladas, especificaciones de protocolo, métricas de desempeño, pruebas de seguridad y registros.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar DNS, DHCP, sincronización temporal para resolver un caso de operación consistente de sistemas clínicos distribuidos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar HTTP, REST, serialización y contratos para resolver un caso de intercambio de información entre aplicaciones sanitarias con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar máquinas virtuales, contenedores, orquestación introductoria para resolver un caso de despliegue reproducible de herramientas biomédicas con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar balanceo, copias de seguridad, métricas, logs y alertas para resolver un caso de continuidad de servicios de salud digital con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar roles, autenticación, secretos y trazabilidad para resolver un caso de protección de acceso a información clínica con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar requisitos, capacidad, recuperación ante fallos para resolver un caso de propuesta de una plataforma biomédica mantenible y resiliente con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Redes y Servicios con precisión.
  • Entrega un diagrama de arquitectura y protocolo de pruebas de red reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

  • Unidad 5: Identidad y seguridad. Integrar roles, autenticación, secretos y trazabilidad para resolver un caso de protección de acceso a información clínica con evidencia, controles, incertidumbre y comunicación proporcional.
