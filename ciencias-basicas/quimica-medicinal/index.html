Química Medicinal

Curso completo de Química Medicinal orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Propósito formativo

Apoya el diseño, evaluación y comprensión de fármacos.

Prerrequisitos recomendados

  • Matemáticas y razonamiento cuantitativo de nivel preuniversitario.
  • Lectura de gráficos, tablas, fórmulas y unidades científicas.
  • Capacidad para documentar procedimientos y comprobar la coherencia de resultados.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Química Medicinal.
  • Aplicar el flujo definir hipótesis molecular → curar estructuras y ensayos → comparar series → probar relación estructura-actividad → evaluar incertidumbre a casos nuevos.
  • Seleccionar y documentar estructuras verificadas, ensayos de actividad, selectividad, propiedades fisicoquímicas y procedencia experimental.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar dianas terapéuticas, validación, cribado y hits para resolver un caso de conexión entre mecanismo de enfermedad y estrategia farmacológica con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar farmacóforos, potencia y selectividad, estereoquímica para resolver un caso de optimización de compuestos candidatos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar pKa y lipofilia, solubilidad, permeabilidad para resolver un caso de predicción de absorción y distribución con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar absorción, biotransformación, transportadores y eliminación para resolver un caso de anticipación de exposición, interacciones y metabolitos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar toxicóforos, off-targets, margen terapéutico para resolver un caso de priorización de candidatos con mejor balance beneficio-riesgo con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar docking introductorio, modelos QSAR, evidencia preclínica para resolver un caso de diseño razonado y comunicación de un proyecto medicinal con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Química Medicinal con precisión.
  • Entrega un informe de relación estructura-actividad con hipótesis verificable reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

    Preguntas de baja carga, mapas corregidos y explicaciones que distinguen evidencia e inferencia.

  • Problemas y casos25 %

    Resoluciones con procedimiento, controles, interpretación, sensibilidad y límites.

  • Laboratorios reproducibles25 %

    Datos abiertos o sintéticos, código o procedimiento, procedencia, pruebas y registro de discrepancias.

  • Revisión por pares10 %

    Uso de rúbrica, clasificación de hallazgos, corrección y justificación antes-después.

  • Proyecto integrador25 %

    Producto acumulativo que conecta las seis unidades y defiende una conclusión proporcional.
