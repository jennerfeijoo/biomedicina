Unidades de Fundamentos de Programación

Bases de programación para resolver problemas de forma computacional.

Todas las unidades disponen de material lectivo, práctica y autoevaluación. Su especificidad, trazabilidad y revisión se informan por separado; el material no sustituye docencia, laboratorio o práctica clínica supervisada.

← Volver al curso

6 unidades

Avanza en orden o entra directamente en la unidad que necesitas.

Unidad 1Algoritmos y tipos de datos

Introducir la programación como especificación ejecutable de procesos reproducibles. La unidad usa Python para representar datos biomédicos simples, construir algoritmos secuenciales, validar entradas y distinguir valores, tipos, variables y operaciones.

Abrir lección → Unidad 2Control de flujo

Construir programas que tomen decisiones, repitan procesos y validen entradas mediante condicionales, bucles y manejo explícito de casos límite, evitando convertir reglas educativas en decisiones clínicas automáticas.

Abrir lección → Unidad 3Funciones y modularidad

Diseñar funciones pequeñas, verificables y reutilizables mediante parámetros, valores de retorno, contratos, alcance, documentación y composición, con énfasis en cálculos biomédicos reproducibles y separación de responsabilidades.

Abrir lección → Unidad 4Colecciones y archivos

Seleccionar y usar listas, tuplas, diccionarios, conjuntos y archivos para representar datos biomédicos con estructura explícita, validación, trazabilidad y manejo seguro de errores.

Abrir lección → Unidad 5Análisis y visualización

Construir análisis exploratorios reproducibles mediante limpieza explícita, resúmenes numéricos y gráficos adecuados, diferenciando descripción, comparación e inferencia en datos biomédicos.

Abrir lección → Unidad 6Calidad de software

Integrar pruebas, manejo de errores, documentación, control de versiones, entornos reproducibles y revisión de código para construir software científico claro, verificable y mantenible.
