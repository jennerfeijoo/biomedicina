Desarrollo teórico

Los conceptos se estudian mediante mecanismos, modelos, evidencia, supuestos y límites de interpretación.

Desarrollo 1

Euler, Runge–Kutta y error

Euler es de primer orden. La formulación debe declarar variables, unidades, dominio y supuestos.

Runge–Kutta usa etapas. La interpretación depende del régimen y de las condiciones del problema.

Error local y global son distintos. El cálculo se verifica mediante sustitución, invariantes, referencias o simulación.

La convergencia debe medirse. Una coincidencia numérica o visual no demuestra por sí sola mecanismo, causalidad ni utilidad clínica.

Puntos de integración

  • Euler es de primer orden
  • Runge–Kutta usa etapas

    Realizar refinamiento.

    Comparar con referencia.

    Comparar método implícito.

Glosario disciplinar

  • Método explícito

    Actualización directa.

  • Método implícito

    Requiere resolver ecuación.

  • Paso temporal

    Incremento de tiempo.

  • Error local

    Error de un paso.

  • Error global

    Error acumulado.

  • Orden

    Tasa de reducción con h.

  • Tolerancia absoluta

    Escala mínima de error.

  • Tolerancia relativa

    Error proporcional.

  • Estabilidad absoluta

    Región de hλ estable.

  • Rigidez

    Escalas muy separadas.

  • Evento

    Condición localizada.

  • Sensibilidad

    Derivada respecto de parámetro.

  • Identificabilidad estructural

    Unicidad con datos ideales.

  • Identificabilidad práctica

    Precisión con datos reales.

  • Verificación

    Resolver bien ecuaciones.

  • Validación

    Adecuación al sistema y propósito.
