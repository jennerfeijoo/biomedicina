Comunicación Científica

Curso completo de Comunicación Científica orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Permite traducir evidencia biomédica para públicos académicos, clínicos y sociales.

Prerrequisitos recomendados

  • Comprensión lectora y escritura académica de nivel universitario.
  • Familiaridad introductoria con ciencia, tecnología y salud.
  • Disposición para analizar perspectivas, evidencia, incertidumbre y consecuencias sociales.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Comunicación Científica.
  • Aplicar el flujo definir propósito y audiencia → jerarquizar afirmaciones → vincular evidencia → expresar incertidumbre → probar comprensión → corregir a casos nuevos.
  • Seleccionar y documentar fuentes primarias, metadatos, citas verificables, pruebas de comprensión y revisión editorial.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar objetivo comunicativo, públicos, contexto y barreras para resolver un caso de adaptación responsable de mensajes biomédicos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar afirmación, evidencia, razonamiento e incertidumbre para resolver un caso de explicación científica sin exagerar resultados con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar resumen, introducción, métodos, resultados y discusión para resolver un caso de producción de manuscritos y reportes claros con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar figuras, tablas, narrativa y diseño accesible para resolver un caso de comunicación de datos biomédicos complejos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar lenguaje llano, formatos digitales, verificación para resolver un caso de contenido público que distingue evidencia y opinión con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar autoría, citación, revisión por pares y correcciones para resolver un caso de difusión científica ética y reproducible con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Comunicación Científica con precisión.
  • Entrega un paquete multiformato con texto académico, figura y versión divulgativa reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

    Producto acumulativo que conecta las seis unidades y defiende una conclusión proporcional.
