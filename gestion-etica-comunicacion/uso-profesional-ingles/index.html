Uso Profesional del Inglés

Curso completo de Uso Profesional del Inglés orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Nivel
Pregrado universitario intermedio y avanzado
Estado editorial
Unidades desarrolladas · revisión experta pendiente

Guía educativa abierta: organiza un recorrido universitario, pero no sustituye el programa oficial de una institución ni otorga certificación.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Facilita lectura científica, colaboración internacional y comunicación académica.

Prerrequisitos recomendados

  • Comprensión lectora y escritura académica de nivel universitario.
  • Familiaridad introductoria con ciencia, tecnología y salud.
  • Disposición para analizar perspectivas, evidencia, incertidumbre y consecuencias sociales.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Uso Profesional del Inglés.
  • Aplicar el flujo definir propósito y audiencia → jerarquizar afirmaciones → vincular evidencia → expresar incertidumbre → probar comprensión → corregir a casos nuevos.
  • Seleccionar y documentar fuentes primarias, metadatos, citas verificables, pruebas de comprensión y revisión editorial.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar vocabulario biomédico, claridad, tono y precisión para resolver un caso de participación en entornos académicos internacionales con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar estructura de artículos, inferencia, lenguaje de incertidumbre para resolver un caso de comprensión de literatura biomédica en inglés con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar correo, resumen, informe y revisión para resolver un caso de comunicación clara con equipos y supervisores con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar pronunciación inteligible, señalización, preguntas y acuerdos para resolver un caso de exposición y colaboración interdisciplinaria con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar procedimientos, requisitos, incidencias y control de cambios para resolver un caso de redacción para laboratorios y dispositivos médicos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar CV, entrevistas, negociación de significado y etiqueta para resolver un caso de integración profesional en ciencia e industria con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Uso Profesional del Inglés con precisión.
  • Entrega un paquete multiformato con texto académico, figura y versión divulgativa reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Evaluación sugerida

  • Recuperación y explicación15 %

    Preguntas de baja carga, mapas corregidos y explicaciones que distinguen evidencia e inferencia.

  • Problemas y casos25 %

    Resoluciones con procedimiento, controles, interpretación, sensibilidad y límites.

  • Laboratorios reproducibles25 %

    Datos abiertos o sintéticos, código o procedimiento, procedencia, pruebas y registro de discrepancias.

  • Revisión por pares10 %

    Uso de rúbrica, clasificación de hallazgos, corrección y justificación antes-después.

  • Proyecto integrador25 %

    Producto acumulativo que conecta las seis unidades y defiende una conclusión proporcional.
