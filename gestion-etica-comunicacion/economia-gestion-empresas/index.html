Economía y Gestión de Empresas

Curso completo de Economía y Gestión de Empresas orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Propósito formativo

Apoya sostenibilidad, gestión e implementación de innovación biomédica.

Prerrequisitos recomendados

  • Comprensión lectora y escritura académica de nivel universitario.
  • Familiaridad introductoria con ciencia, tecnología y salud.
  • Disposición para analizar perspectivas, evidencia, incertidumbre y consecuencias sociales.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Economía y Gestión de Empresas.
  • Aplicar el flujo definir problema público → mapear actores y valores → comparar alternativas → evaluar consecuencias y equidad → justificar decisión → planificar revisión a casos nuevos.
  • Seleccionar y documentar documentos normativos, datos de implementación, análisis económico, deliberación ética y perspectivas de partes interesadas.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar escasez, coste de oportunidad, oferta y demanda para resolver un caso de comprensión de decisiones bajo recursos limitados con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar estados financieros, costes, flujo de caja para resolver un caso de evaluación básica de sostenibilidad de proyectos biomédicos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar capacidad, calidad, inventario y mejora para resolver un caso de gestión de laboratorios y servicios sanitarios con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar segmentación, competencia, propuesta de valor para resolver un caso de posicionamiento de soluciones de tecnología médica con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar coste-efectividad, presupuesto, sensibilidad para resolver un caso de comparación transparente de alternativas sanitarias con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar estructura organizativa, KPIs, riesgo y cumplimiento para resolver un caso de gestión responsable de una organización biomédica con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Economía y Gestión de Empresas con precisión.
  • Entrega un memorando de decisión con alternativas, evidencia y salvaguardas reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Evaluación sugerida

  • Recuperación y explicación15 %

    Preguntas de baja carga, mapas corregidos y explicaciones que distinguen evidencia e inferencia.

  • Problemas y casos25 %

    Resoluciones con procedimiento, controles, interpretación, sensibilidad y límites.

  • Laboratorios reproducibles25 %

    Datos abiertos o sintéticos, código o procedimiento, procedencia, pruebas y registro de discrepancias.

  • Revisión por pares10 %

    Uso de rúbrica, clasificación de hallazgos, corrección y justificación antes-después.

  • Proyecto integrador25 %

    Producto acumulativo que conecta las seis unidades y defiende una conclusión proporcional.
