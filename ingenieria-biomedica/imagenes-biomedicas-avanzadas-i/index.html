Imágenes Biomédicas Avanzadas I

Curso completo de Imágenes Biomédicas Avanzadas I orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Apoya diagnóstico avanzado, investigación clínica y procesamiento de imágenes.

Prerrequisitos recomendados

  • Álgebra, cálculo y física de nivel universitario inicial.
  • Programación básica para análisis numérico y visualización.
  • Fundamentos de biología o fisiología pertinentes al sistema estudiado.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Imágenes Biomédicas Avanzadas I.
  • Aplicar el flujo definir tarea de imagen → auditar adquisición → procesar sin fuga → cuantificar → comparar referencia → analizar generalización a casos nuevos.
  • Seleccionar y documentar datos originales, metadatos DICOM, fantomas o referencias, métricas, anotaciones y evaluación externa.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar transformada de Radon, retroproyección, reconstrucción iterativa para resolver un caso de mejora de CT y reducción de artefactos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar espacio k, secuencias, difusión y perfusión para resolver un caso de caracterización funcional y microestructural con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar beamforming, Doppler, elastografía para resolver un caso de evaluación de flujo y rigidez tisular con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar correcciones, reconstrucción, SUV y cinética para resolver un caso de cuantificación de procesos moleculares con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar transformaciones, métricas de similitud, multimodalidad para resolver un caso de integración anatómica y funcional con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar fantomas, reproducibilidad, incertidumbre para resolver un caso de validación de biomarcadores de imagen con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Imágenes Biomédicas Avanzadas I con precisión.
  • Entrega un pipeline de imagen reproducible con informe cuantitativo reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Módulos del curso

  • Unidad 1: Reconstrucción tomográfica. Integrar transformada de Radon, retroproyección, reconstrucción iterativa para resolver un caso de mejora de CT y reducción de artefactos con evidencia, controles, incertidumbre y comunicación proporcional.

Unidad 1Reconstrucción tomográfica

Reconstruir y auditar imágenes de CT a partir de datos de proyección sintéticos, conectando el modelo de transmisión de rayos X con transformada de Radon, sinograma, retroproyección filtrada y métodos iterativos; analizar muestreo, regularización, artefactos y calidad de imagen con métricas dependientes de la tarea, metadatos de reconstrucción y límites explícitos antes de transferir una conclusión a otro protocolo o sistema.

Abrir lección → Unidad 2MRI avanzada

Reconstruir y auditar experimentos de MRI avanzada con datos sintéticos, conectando magnetización y codificación espacial con k-space, secuencias y contraste; analizar muestreo, aceleración y artefactos; estimar difusión mediante b-values y ADC y diferenciar estrategias de perfusión ASL, DSC y DCE, conservando metadatos, supuestos, incertidumbre y límites antes de interpretar cualquier parámetro como sustituto microestructural, hemodinámico o clínico.

Abrir lección → Unidad 3Ultrasonido avanzado

Reconstruir y auditar un pipeline avanzado de ultrasonido con datos exclusivamente sintéticos, conectando señales de elementos de un array con beamforming, imagen B-mode y adquisiciones ultrarrápidas; estimar flujo mediante Doppler con geometría, PRF y aliasing explícitos; diferenciar elastografía por deformación y por onda de corte; y conservar calibración, metadatos, incertidumbre y límites antes de interpretar velocidad, flujo o propiedades mecánicas como biomarcadores o afirmaciones clínicas.
