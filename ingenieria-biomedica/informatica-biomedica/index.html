Informática Biomédica

Curso completo de Informática Biomédica orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Nivel
Pregrado universitario intermedio y avanzado
Estado editorial
Unidades desarrolladas · revisión experta pendiente

Guía educativa abierta: organiza un recorrido universitario, pero no sustituye el programa oficial de una institución ni otorga certificación.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Base para salud digital, datos clínicos e investigación translacional.

Prerrequisitos recomendados

  • Fundamentos de programación: variables, control de flujo, funciones y archivos.
  • Álgebra y razonamiento lógico de nivel universitario inicial.
  • Uso básico de terminal, control de versiones y documentación técnica.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Informática Biomédica.
  • Aplicar el flujo definir uso y unidad de observación → modelar datos y significado → implementar transformación → validar técnica y clínicamente → vigilar desempeño a casos nuevos.
  • Seleccionar y documentar diccionarios, perfiles de datos, pruebas de interoperabilidad, métricas de desempeño, auditorías y evaluación de uso.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar tipos de datos, ciclo de vida, procedencia para resolver un caso de transformación de registros en información útil con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar EHR, laboratorio, imagen y farmacia para resolver un caso de comprensión de flujos y dependencias hospitalarias con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar FHIR, DICOM, SNOMED CT y LOINC para resolver un caso de intercambio semántico de información con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar cohortes, modelos, alertas y evaluación para resolver un caso de uso prudente de datos para mejorar atención con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar usabilidad, carga cognitiva, flujo de trabajo para resolver un caso de prevención de errores por diseño con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar privacidad, seguridad, calidad y cambio organizativo para resolver un caso de implantación sostenible de sistemas clínicos con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Informática Biomédica con precisión.
  • Entrega un prototipo reproducible con contrato de datos y plan de validación reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Módulos del curso

  • Unidad 1: Datos, información y conocimiento en salud. Integrar tipos de datos, ciclo de vida, procedencia para resolver un caso de transformación de registros en información útil con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 2: Sistemas de información clínica. Integrar EHR, laboratorio, imagen y farmacia para resolver un caso de comprensión de flujos y dependencias hospitalarias con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 3: Interoperabilidad y terminologías. Integrar FHIR, DICOM, SNOMED CT y LOINC para resolver un caso de intercambio semántico de información con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 4: Analítica y apoyo a decisiones. Integrar cohortes, modelos, alertas y evaluación para resolver un caso de uso prudente de datos para mejorar atención con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 5: Interacción y factores humanos. Integrar usabilidad, carga cognitiva, flujo de trabajo para resolver un caso de prevención de errores por diseño con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 6: Gobernanza e implementación. Integrar privacidad, seguridad, calidad y cambio organizativo para resolver un caso de implantación sostenible de sistemas clínicos con evidencia, controles, incertidumbre y comunicación proporcional.

Evaluación sugerida

  • Recuperación y explicación15 %

    Preguntas de baja carga, mapas corregidos y explicaciones que distinguen evidencia e inferencia.

  • Problemas y casos25 %

    Resoluciones con procedimiento, controles, interpretación, sensibilidad y límites.

  • Laboratorios reproducibles25 %

    Datos abiertos o sintéticos, código o procedimiento, procedencia, pruebas y registro de discrepancias.

  • Revisión por pares10 %

    Uso de rúbrica, clasificación de hallazgos, corrección y justificación antes-después.

  • Proyecto integrador25 %

    Producto acumulativo que conecta las seis unidades y defiende una conclusión proporcional.
