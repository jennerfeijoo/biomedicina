Desarrollo teórico

Los conceptos se estudian mediante mecanismos, modelos, evidencia, supuestos y límites de interpretación.

Desarrollo 1

1. La medición comienza antes del sensor

Etiquetas como temperatura corporal, presión arterial o actividad cardíaca no especifican por sí solas qué se pretende medir. El mensurando necesita cantidad, portador, localización, estado, intervalo, condiciones y uso previsto.

El nivel de detalle debe ser suficiente para que otra persona pueda decidir si dos resultados responden a la misma pregunta. El método puede formar parte de una definición operacional, pero no sustituye a la cantidad pretendida.

El uso previsto orienta requisitos de rango, incertidumbre y comparabilidad; no convierte una observación en evidencia clínica.

Puntos de integración

  • El nombre del fenómeno no basta.
  • Las condiciones cambian significado y comparabilidad.
  • El uso previsto limita la conclusión.

Desarrollo 2

2. De fenómeno a resultado

Un fenómeno biológico modifica cantidades físicas o químicas. El sensor interactúa con ellas, produce una señal y el sistema entrega una indicación. La indicación puede ser un voltaje, una cuenta digital o un valor ya convertido.

El resultado reúne el valor atribuido al mensurando y la información necesaria para interpretarlo: unidad, incertidumbre, referencia, localización, condiciones, versión del algoritmo y advertencias.

Una matriz de números sin frecuencia de muestreo, ganancia, canales y procedencia conserva estructura, pero pierde significado físico.

Puntos de integración

  • Señal e indicación no son el mensurando.
  • El resultado incluye metadatos.
  • El display no elimina las transformaciones internas.

Desarrollo 3

3. Sistema, cadena, modelo y trazabilidad

El sistema de medición puede incluir interfaz, sensor, excitación, acondicionamiento, conversión, reloj, software y tablas de calibración. La cadena sigue la ruta de señal; el modelo relaciona las cantidades usadas para atribuir el resultado.

Las fronteras deben declararse porque determinan qué efectos se consideran internos, externos o propios del procedimiento.

La trazabilidad metrológica conecta resultados con referencias mediante una cadena documentada de calibraciones e incertidumbres. No significa ausencia de sesgo ni validez clínica.

Puntos de integración

  • Cadena y modelo responden preguntas distintas.
  • Las fronteras deben ser explícitas.
  • Trazabilidad no es exactitud absoluta.

Ejemplos y casos resueltos

Termometría de contacto

Situación. Un sensor toca la piel y reporta una temperatura.

Razonamiento paso a paso

  1. Definir superficie y localización.
  2. Declarar el intervalo tras el contacto.
  3. Separar temperatura del sensor, piel y ambiente.
  4. Limitar la interpretación.

Interpretación. El resultado depende de contacto, dinámica y condiciones; no es una lectura directa de temperatura central.

Limitaciones

  • Modelo educativo.
  • Sin validación clínica.

Actividad aplicada

Mapa de una cadena de medición

Procedimiento

  1. Elegir un caso biomédico.
  2. Especificar el mensurando.
  3. Dibujar transformaciones y fronteras.
  4. Añadir metadatos y límites.

Problemas y tareas

  • Distinguir fenómeno y cantidad.
  • Identificar la indicación.
  • Localizar una posible pérdida de trazabilidad.

Criterios de comprobación

  • Unidades explícitas.
  • Frontera declarada.
  • Conclusión proporcional a la evidencia.

Errores frecuentes y autoevaluación

Errores frecuentes y corrección

  • Llamar mensurando al dispositivo.

    Nombrar la cantidad pretendida y sus condiciones.

  • Tratar una señal como resultado completo.

    Añadir escala, referencia, metadatos e incertidumbre.

  • Usar trazabilidad como sinónimo de exactitud.

    Separar cadena de referencias, sesgo e incertidumbre.

1. ¿Qué es el mensurando?

Respuesta: La cantidad que se pretende medir, suficientemente especificada.

2. ¿Qué diferencia indicación y resultado?

Respuesta: La indicación es una salida; el resultado añade el valor atribuido y la información necesaria para interpretarlo.

3. ¿Qué aporta la trazabilidad?

Respuesta: Una relación documentada con referencias mediante calibraciones e incertidumbres.
