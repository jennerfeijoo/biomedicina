Fundamentos de Biomecánica

Curso completo de Fundamentos de Biomecánica orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Propósito formativo

Soporte para rehabilitación, ergonomía, ortopedia y diseño de prótesis.

Prerrequisitos recomendados

  • Matemáticas, física y programación de nivel universitario inicial.
  • Bases de biología celular, anatomía o fisiología humana.
  • Capacidad para documentar requisitos, supuestos, mediciones y resultados.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Fundamentos de Biomecánica.
  • Aplicar el flujo idealizar sistema → definir coordenadas y cargas → formular balances → resolver → verificar → validar y analizar sensibilidad a casos nuevos.
  • Seleccionar y documentar cinemática, fuerzas, propiedades constitutivas, calibración, convergencia y comparación experimental.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar diagramas de cuerpo libre, equilibrio, torque para resolver un caso de análisis básico de postura y movimiento con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar posición, velocidad, aceleración angular y lineal para resolver un caso de descripción cuantitativa de tareas funcionales con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar leyes de Newton, impulso, trabajo y potencia para resolver un caso de interpretación de carga y rendimiento con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar esfuerzo y deformación, elasticidad, viscoelasticidad para resolver un caso de comprensión de adaptación y lesión con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar segmentos, centros de masa, rangos y palancas para resolver un caso de modelos musculoesqueléticos introductorios con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar video, fuerza, errores e incertidumbre para resolver un caso de realización de una evaluación reproducible de movimiento con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Fundamentos de Biomecánica con precisión.
  • Entrega un modelo mecánico documentado con verificación y límites reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Módulos del curso

  • Unidad 1: Vectores, fuerzas y momentos. Integrar diagramas de cuerpo libre, equilibrio, torque para resolver un caso de análisis básico de postura y movimiento con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 2: Cinemática. Integrar posición, velocidad, aceleración angular y lineal para resolver un caso de descripción cuantitativa de tareas funcionales con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 3: Dinámica y energía. Integrar leyes de Newton, impulso, trabajo y potencia para resolver un caso de interpretación de carga y rendimiento con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 4: Propiedades mecánicas de tejidos. Integrar esfuerzo y deformación, elasticidad, viscoelasticidad para resolver un caso de comprensión de adaptación y lesión con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 5: Antropometría y articulaciones. Integrar segmentos, centros de masa, rangos y palancas para resolver un caso de modelos musculoesqueléticos introductorios con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 6: Medición biomecánica. Integrar video, fuerza, errores e incertidumbre para resolver un caso de realización de una evaluación reproducible de movimiento con evidencia, controles, incertidumbre y comunicación proporcional.
