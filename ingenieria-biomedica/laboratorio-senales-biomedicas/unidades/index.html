Unidades de Laboratorio de Señales Biomédicas

Curso completo de Laboratorio de Señales Biomédicas orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Todas las unidades tienen contenido lectivo, práctica y autoevaluación. El material permanece abierto a revisión de especialistas y no sustituye docencia, laboratorio o práctica clínica supervisada.

6 unidades

Avanza en orden o entra directamente en la unidad que necesitas.

Unidad 1Adquisición y seguridad

Integrar electrodos, muestreo, consentimiento y protocolo para resolver un caso de registro confiable de señales fisiológicas con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 2Inspección y calidad

Integrar visualización, artefactos, segmentos válidos para resolver un caso de prevención de análisis sobre datos defectuosos con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 3Preprocesamiento

Integrar filtrado, línea base, remuestreo y normalización para resolver un caso de mejora controlada de ECG, EMG o PPG con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 4Extracción de eventos

Integrar picos, intervalos, envolventes y detección para resolver un caso de cuantificación de ritmo y actividad con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 5Características y comparación

Integrar tiempo, frecuencia, variabilidad y estadística para resolver un caso de diferenciación de estados fisiológicos con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 6Pipeline reproducible

Integrar código, pruebas, figuras y reporte para resolver un caso de entrega auditable de un análisis de señal con evidencia, controles, incertidumbre y comunicación proporcional.
