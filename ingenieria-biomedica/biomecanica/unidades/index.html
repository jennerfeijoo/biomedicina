Unidades de Biomecánica

Curso completo de Biomecánica orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Todas las unidades tienen contenido lectivo, práctica y autoevaluación. El material permanece abierto a revisión de especialistas y no sustituye docencia, laboratorio o práctica clínica supervisada.

← Volver al curso

6 unidades

Avanza en orden o entra directamente en la unidad que necesitas.

Unidad 1Cinemática del movimiento humano

Integrar posición y orientación, velocidad, análisis 2D y 3D para resolver un caso de cuantificación de marcha y movimiento funcional con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 2Cinética

Integrar fuerzas externas, momentos, dinámica inversa para resolver un caso de estimación de cargas articulares con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 3Mecánica musculoesquelética

Integrar músculo-tendón, palancas, reclutamiento para resolver un caso de interpretación de fuerza, fatiga y compensación con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 4Tejidos biológicos

Integrar hueso, cartílago, tendón y viscoelasticidad para resolver un caso de relación entre carga, adaptación y lesión con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 5Medición y modelado

Integrar plataformas de fuerza, EMG, captura y errores para resolver un caso de integración de datos biomecánicos con evidencia, controles, incertidumbre y comunicación proporcional.

Abrir lección → Unidad 6Aplicaciones clínicas

Integrar marcha patológica, ergonomía, prótesis y rehabilitación para resolver un caso de evaluación de una intervención con métricas biomecánicas con evidencia, controles, incertidumbre y comunicación proporcional.
