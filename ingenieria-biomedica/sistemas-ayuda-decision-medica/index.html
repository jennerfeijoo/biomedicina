Sistemas de Ayuda a la Decisión Médica

Curso completo de Sistemas de Ayuda a la Decisión Médica orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Nivel
Pregrado universitario intermedio y avanzado
Estado editorial
Unidades desarrolladas · revisión experta pendiente

Guía educativa abierta: organiza un recorrido universitario, pero no sustituye el programa oficial de una institución ni otorga certificación.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Integra datos, conocimiento clínico, modelos y evaluación de evidencia.

Prerrequisitos recomendados

  • Matemáticas, física y programación de nivel universitario inicial.
  • Bases de biología celular, anatomía o fisiología humana.
  • Capacidad para documentar requisitos, supuestos, mediciones y resultados.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Sistemas de Ayuda a la Decisión Médica.
  • Aplicar el flujo definir uso y unidad de observación → modelar datos y significado → implementar transformación → validar técnica y clínicamente → vigilar desempeño a casos nuevos.
  • Seleccionar y documentar diccionarios, perfiles de datos, pruebas de interoperabilidad, métricas de desempeño, auditorías y evaluación de uso.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar usuarios, flujo, decisión y acción para resolver un caso de definición de una ayuda útil y no intrusiva con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar guías, lógica, ontologías y mantenimiento para resolver un caso de sistemas basados en conocimiento trazable con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar riesgo, discriminación, calibración y umbrales para resolver un caso de estimación que apoya decisiones concretas con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar EHR, alertas, explicaciones y fatiga para resolver un caso de entrega de información en el momento adecuado con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar datos externos, subgrupos, utilidad y seguridad para resolver un caso de demostración de beneficio antes de implementación con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar responsabilidad, sesgo, drift y auditoría para resolver un caso de operación segura de apoyo a decisiones con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Sistemas de Ayuda a la Decisión Médica con precisión.
  • Entrega un prototipo reproducible con contrato de datos y plan de validación reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Módulos del curso

  • Unidad 1: Decisión clínica y casos de uso. Integrar usuarios, flujo, decisión y acción para resolver un caso de definición de una ayuda útil y no intrusiva con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 2: Conocimiento y reglas. Integrar guías, lógica, ontologías y mantenimiento para resolver un caso de sistemas basados en conocimiento trazable con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 3: Modelos predictivos. Integrar riesgo, discriminación, calibración y umbrales para resolver un caso de estimación que apoya decisiones concretas con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 4: Integración e interfaz. Integrar EHR, alertas, explicaciones y fatiga para resolver un caso de entrega de información en el momento adecuado con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 5: Validación clínica. Integrar datos externos, subgrupos, utilidad y seguridad para resolver un caso de demostración de beneficio antes de implementación con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 6: Gobernanza y monitorización. Integrar responsabilidad, sesgo, drift y auditoría para resolver un caso de operación segura de apoyo a decisiones con evidencia, controles, incertidumbre y comunicación proporcional.

    Datos abiertos o sintéticos, código o procedimiento, procedencia, pruebas y registro de discrepancias.

    Uso de rúbrica, clasificación de hallazgos, corrección y justificación antes-después.

    Producto acumulativo que conecta las seis unidades y defiende una conclusión proporcional.
