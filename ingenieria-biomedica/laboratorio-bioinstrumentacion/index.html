Laboratorio de Bioinstrumentación

Curso completo de Laboratorio de Bioinstrumentación orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Nivel
Pregrado universitario intermedio y avanzado
Estado editorial
Unidades desarrolladas · revisión experta pendiente

Propósito formativo

Integra sensores, circuitos, señales y medición fisiológica.

Prerrequisitos recomendados

  • Matemáticas, física y programación de nivel universitario inicial.
  • Bases de biología celular, anatomía o fisiología humana.
  • Capacidad para documentar requisitos, supuestos, mediciones y resultados.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Laboratorio de Bioinstrumentación.
  • Aplicar el flujo especificar mensurando → presupuestar rango y banda → modelar cadena → simular fallos → verificar salida a casos nuevos.
  • Seleccionar y documentar señal cruda, función de transferencia, calibración, espectro, incertidumbre y pruebas de límites.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar riesgo eléctrico, incertidumbre, documentación para resolver un caso de trabajo experimental trazable y seguro con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar calibración, sensibilidad, histéresis y deriva para resolver un caso de evaluación de transductores biomédicos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar electrodos, amplificador diferencial, rechazo de modo común para resolver un caso de registro de ECG o EMG con controles con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar filtros, muestreo, cuantización y artefactos para resolver un caso de conservación de información fisiológica con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar hardware, firmware, comunicación y carcasa para resolver un caso de construcción de un sistema de medición funcional con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar plan de pruebas, resultados, incertidumbre y fallos para resolver un caso de demostración documentada de desempeño con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Laboratorio de Bioinstrumentación con precisión.
  • Entrega un expediente de cadena de señal con presupuestos y pruebas reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Módulos del curso

  • Unidad 1: Seguridad, metrología y bitácora. Integrar riesgo eléctrico, incertidumbre, documentación para resolver un caso de trabajo experimental trazable y seguro con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 2: Caracterización de sensores. Integrar calibración, sensibilidad, histéresis y deriva para resolver un caso de evaluación de transductores biomédicos con evidencia, controles, incertidumbre y comunicación proporcional.

  • Unidad 4: Filtrado y adquisición. Integrar filtros, muestreo, cuantización y artefactos para resolver un caso de conservación de información fisiológica con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 5: Integración de prototipo. Integrar hardware, firmware, comunicación y carcasa para resolver un caso de construcción de un sistema de medición funcional con evidencia, controles, incertidumbre y comunicación proporcional.

Unidad 1Seguridad, metrología y bitácora

Establecer una práctica de laboratorio reproducible y proporcional al riesgo antes de medir: delimitar peligros y fronteras de seguridad, definir el mensurando, distinguir calibración de verificación y ajuste, construir trazabilidad metrológica, estimar incertidumbre y mantener una bitácora capaz de reconstruir decisiones y desviaciones. Todas las actividades de esta unidad usan escenarios sintéticos, simulación o equipos educativos bajo procedimientos institucionales; no autorizan conexión a personas ni trabajo con red eléctrica.
