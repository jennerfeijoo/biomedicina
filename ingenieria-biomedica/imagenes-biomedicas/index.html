Imágenes Biomédicas

Curso completo de Imágenes Biomédicas orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Base para diagnóstico, planificación y seguimiento clínico.

Prerrequisitos recomendados

  • Matemáticas, física y programación de nivel universitario inicial.
  • Bases de biología celular, anatomía o fisiología humana.
  • Capacidad para documentar requisitos, supuestos, mediciones y resultados.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Imágenes Biomédicas.
  • Aplicar el flujo definir tarea de imagen → auditar adquisición → procesar sin fuga → cuantificar → comparar referencia → analizar generalización a casos nuevos.
  • Seleccionar y documentar datos originales, metadatos DICOM, fantomas o referencias, métricas, anotaciones y evaluación externa.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar muestreo espacial, píxel y vóxel, resolución y contraste para resolver un caso de lectura técnica de imágenes médicas con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar atenuación, proyecciones, reconstrucción CT para resolver un caso de evaluación de estructuras anatómicas y dosis con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar magnetización, relajación, codificación espacial para resolver un caso de selección de contrastes para tejidos blandos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar propagación acústica, transductores, modos de imagen para resolver un caso de imagen en tiempo real y Doppler con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar trazadores, detección, PET/SPECT y modalidades ópticas para resolver un caso de imagen funcional y molecular con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar resolución, ruido, controles y riesgos para resolver un caso de comparación responsable de modalidades con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Imágenes Biomédicas con precisión.
  • Entrega un pipeline de imagen reproducible con informe cuantitativo reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

  • Unidad 4: Ultrasonido. Integrar propagación acústica, transductores, modos de imagen para resolver un caso de imagen en tiempo real y Doppler con evidencia, controles, incertidumbre y comunicación proporcional.
