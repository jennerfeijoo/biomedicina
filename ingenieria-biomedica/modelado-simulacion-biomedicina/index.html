Modelado y Simulación en Biomedicina

Curso completo de Modelado y Simulación en Biomedicina orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Permite explorar procesos fisiológicos, dispositivos y escenarios clínicos.

Prerrequisitos recomendados

  • Álgebra, cálculo y física de nivel universitario inicial.
  • Programación básica para análisis numérico y visualización.
  • Fundamentos de biología o fisiología pertinentes al sistema estudiado.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Modelado y Simulación en Biomedicina.
  • Aplicar el flujo idealizar sistema → definir coordenadas y cargas → formular balances → resolver → verificar → validar y analizar sensibilidad a casos nuevos.
  • Seleccionar y documentar cinemática, fuerzas, propiedades constitutivas, calibración, convergencia y comparación experimental.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar pregunta, escala, supuestos y variables para resolver un caso de representación útil de un problema biomédico con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar EDO, compartimentos, estado y parámetros para resolver un caso de simulación de farmacocinética y fisiología con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar azar, transición de estados, heterogeneidad para resolver un caso de estudio de poblaciones celulares o procesos asistenciales con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar ajuste, identificabilidad, análisis local y global para resolver un caso de determinación de parámetros influyentes con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar pruebas, datos de referencia, incertidumbre para resolver un caso de separación de error numérico y error de modelo con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar escenarios, comunicación, límites y ética para resolver un caso de uso responsable de modelos en diseño o clínica con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Modelado y Simulación en Biomedicina con precisión.
  • Entrega un modelo mecánico documentado con verificación y límites reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Módulos del curso

  • Unidad 1: Formulación del modelo. Integrar pregunta, escala, supuestos y variables para resolver un caso de representación útil de un problema biomédico con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 2: Modelos deterministas. Integrar EDO, compartimentos, estado y parámetros para resolver un caso de simulación de farmacocinética y fisiología con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 3: Modelos estocásticos y de agentes. Integrar azar, transición de estados, heterogeneidad para resolver un caso de estudio de poblaciones celulares o procesos asistenciales con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 4: Estimación y sensibilidad. Integrar ajuste, identificabilidad, análisis local y global para resolver un caso de determinación de parámetros influyentes con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 5: Verificación y validación. Integrar pruebas, datos de referencia, incertidumbre para resolver un caso de separación de error numérico y error de modelo con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 6: Simulación para decisiones. Integrar escenarios, comunicación, límites y ética para resolver un caso de uso responsable de modelos en diseño o clínica con evidencia, controles, incertidumbre y comunicación proporcional.
