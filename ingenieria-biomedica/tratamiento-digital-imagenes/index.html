Tratamiento Digital de Imágenes

Curso completo de Tratamiento Digital de Imágenes orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Base para análisis de imagen médica, segmentación y cuantificación.

Prerrequisitos recomendados

  • Álgebra, cálculo y física de nivel universitario inicial.
  • Programación básica para análisis numérico y visualización.
  • Fundamentos de biología o fisiología pertinentes al sistema estudiado.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Tratamiento Digital de Imágenes.
  • Aplicar el flujo definir tarea de imagen → auditar adquisición → procesar sin fuga → cuantificar → comparar referencia → analizar generalización a casos nuevos.
  • Seleccionar y documentar datos originales, metadatos DICOM, fantomas o referencias, métricas, anotaciones y evaluación externa.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar muestreo y cuantización, histogramas, color y formatos para resolver un caso de representación correcta de imágenes biomédicas con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar contraste, ecualización, corrección gamma para resolver un caso de mejora visual con preservación de significado con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar convolución, suavizado, realce y ruido para resolver un caso de preprocesamiento de microscopía e imagen médica con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar Fourier 2D, filtros, artefactos periódicos para resolver un caso de separación de componentes y restauración con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar operadores morfológicos, umbral, bordes y regiones para resolver un caso de delimitación de células, órganos y lesiones con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar métricas, verdad de referencia, sensibilidad a parámetros para resolver un caso de validación de un pipeline de procesamiento con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Tratamiento Digital de Imágenes con precisión.
  • Entrega un pipeline de imagen reproducible con informe cuantitativo reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Módulos del curso

  • Unidad 1: Imagen digital. Integrar muestreo y cuantización, histogramas, color y formatos para resolver un caso de representación correcta de imágenes biomédicas con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 2: Transformaciones de intensidad. Integrar contraste, ecualización, corrección gamma para resolver un caso de mejora visual con preservación de significado con evidencia, controles, incertidumbre y comunicación proporcional.

  • Unidad 4: Procesamiento frecuencial. Integrar Fourier 2D, filtros, artefactos periódicos para resolver un caso de separación de componentes y restauración con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 5: Morfología y segmentación. Integrar operadores morfológicos, umbral, bordes y regiones para resolver un caso de delimitación de células, órganos y lesiones con evidencia, controles, incertidumbre y comunicación proporcional.
  • Unidad 6: Evaluación y reproducibilidad. Integrar métricas, verdad de referencia, sensibilidad a parámetros para resolver un caso de validación de un pipeline de procesamiento con evidencia, controles, incertidumbre y comunicación proporcional.
