Biofotónica

Curso completo de Biofotónica orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

Propósito formativo

Relevante para imagen, diagnóstico óptico y terapias basadas en luz.

Prerrequisitos recomendados

  • Álgebra, cálculo y física de nivel universitario inicial.
  • Programación básica para análisis numérico y visualización.
  • Fundamentos de biología o fisiología pertinentes al sistema estudiado.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Biofotónica.
  • Aplicar el flujo especificar mensurando → presupuestar rango y banda → modelar cadena → simular fallos → verificar salida a casos nuevos.
  • Seleccionar y documentar señal cruda, función de transferencia, calibración, espectro, incertidumbre y pruebas de límites.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar absorción, dispersión, anisotropía y profundidad para resolver un caso de selección de longitudes de onda para diagnóstico y terapia con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar láseres y LED, fotodiodos, ruido y sensibilidad para resolver un caso de diseño de sistemas ópticos biomédicos con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar transporte radiativo, modelos de difusión, fantomas para resolver un caso de estimación de propiedades tisulares con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar fluorescencia, confocal, Raman y OCT para resolver un caso de imagen y caracterización molecular sin etiquetado con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar interacción fotoquímica y térmica, entrega de energía, seguridad para resolver un caso de terapia fotodinámica y aplicaciones láser con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar calibración, contraste y resolución, normas de seguridad para resolver un caso de evaluación de un dispositivo biofotónico con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Biofotónica con precisión.
  • Entrega un expediente de cadena de señal con presupuestos y pruebas reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.
