Ingeniería Neurosensorial

Curso completo de Ingeniería Neurosensorial orientado a comprender, aplicar, verificar y comunicar sus métodos en problemas biomédicos. Integra teoría, casos, práctica reproducible, controles, incertidumbre, revisión y transferencia responsable.

En esta asignatura Propósito Objetivos Unidades Prácticas Evaluación Recursos

Propósito formativo

Relevante para neurotecnología, interfaces y rehabilitación.

Prerrequisitos recomendados

  • Matemáticas, física y programación de nivel universitario inicial.
  • Bases de biología celular, anatomía o fisiología humana.
  • Capacidad para documentar requisitos, supuestos, mediciones y resultados.

Competencias del curso

  • Construir modelos conceptuales rigurosos en Ingeniería Neurosensorial.
  • Aplicar el flujo especificar mensurando → presupuestar rango y banda → modelar cadena → simular fallos → verificar salida a casos nuevos.
  • Seleccionar y documentar señal cruda, función de transferencia, calibración, espectro, incertidumbre y pruebas de límites.
  • Diseñar controles, casos límite y análisis de sensibilidad.
  • Producir resultados reproducibles con procedencia, parámetros, versiones y registro de cambios.
  • Comunicar a audiencias académicas y generales sin exagerar evidencia ni alcance.

Objetivos de aprendizaje

  • Integrar transducción, codificación, vías y percepción para resolver un caso de definición de señales relevantes para neurotecnología con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar electrodos, EEG y potenciales evocados, ruido para resolver un caso de adquisición segura de actividad nerviosa con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar eléctrica, magnética, parámetros y seguridad para resolver un caso de modulación de circuitos con control de riesgo con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar auditivas, visuales, somatosensoriales para resolver un caso de restauración parcial de funciones sensoriales con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar características, clasificación, adaptación para resolver un caso de control mediante señales neurales con evidencia, controles, incertidumbre y comunicación proporcional.
  • Integrar desempeño, plasticidad, autonomía y privacidad para resolver un caso de evaluación centrada en la persona de una neurotecnología con evidencia, controles, incertidumbre y comunicación proporcional.

Resultados de aprendizaje evaluables

  • Explica y relaciona los dominios centrales de Ingeniería Neurosensorial con precisión.
  • Entrega un expediente de cadena de señal con presupuestos y pruebas reproducible y auditable.
  • Resuelve problemas inéditos declarando unidades, supuestos, controles y límites.
  • Compara una explicación principal con alternativas y propone pruebas discriminantes.
  • Evalúa sensibilidad, incertidumbre, riesgo de sesgo y transferibilidad.
  • Corrige un producto después de revisión y justifica cada cambio.
  • Distingue desempeño técnico, validez científica, utilidad y evidencia clínica o regulatoria.

Unidad 1Sistemas sensoriales

Construir un modelo comparativo de sistemas sensoriales que conecte estímulo físico o químico, receptor, transducción, potencial receptor, actividad aferente, campos receptivos, vías y mapas neurales con variables perceptuales, distinguiendo con precisión qué se mide, qué se codifica y qué se infiere. La unidad cuantifica sensibilidad, saturación, adaptación, resolución espacial y discriminación con estímulos y respuestas sintéticas, y prepara requisitos fisiológicos para neurotecnología sin invadir registro neural, electrodos, estimulación o interfaces de unidades posteriores ni convertir actividad neural en una medida directa de experiencia subjetiva.
